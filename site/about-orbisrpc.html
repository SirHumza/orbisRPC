What is orbisRPC?

orbisRPC (often searched as orbisrpc ps4, or written orbis rpc) is a free, open-source Discord Rich Presence daemon for the jailbroken PlayStation 4 running GoldHEN. It shows the game you're playing — name, cover art and play timer — on your Discord profile, and it runs entirely on the console with no PC.

What orbisRPC is

orbisRPC is a Discord Rich Presence daemon and payload for the jailbroken PlayStation 4 (GoldHEN). It detects the game in the foreground, resolves its name and cover art, and posts the activity to Discord over TLS — all on the console itself.

  • Shows your current PS4 game, its cover art and an elapsed play timer on Discord.
  • Runs as a background GoldHEN payload — no PC, script or FTP bridge at runtime.
  • Supports jailbroken firmware 5.05 through 13.52 (9.00–13.52 verified).
  • Covers retail titles (Sony TMDB), homebrew (pkg-zone) and 28,000+ PS1/PS2/PSP classics.
  • Installs in about five minutes from a single setup PKG.
  • Free and open source: github.com/SirHumza/orbisRPC

The name comes from Orbis, Sony's internal codename for the PlayStation 4. Searching orbisrpc ps4 is simply a search for this project on the PS4 — it is the same tool as orbisRPC.

What orbisRPC is not

Several unrelated projects share the word "Orbis". orbisRPC is none of them.

Not Orbis OSOrbis OS is the FreeBSD-based operating system Sony ships on the PS4. orbisRPC is an app that runs on it, not the OS.
Not OrbisProOrbisPro is an unrelated Windows shell that copies the PS4 interface on a PC. orbisRPC is for the actual console.
Not OpenOrbisOpenOrbis is a developer toolchain for building PS4 homebrew. orbisRPC is an end-user app, not a toolchain.
Not ORBISPatchesORBISPatches is an archive of PS4 game update files. orbisRPC is a Discord presence tool.
Not Orbis ProtocolOrbis Protocol is a Web3 / Ceramic social protocol. orbisRPC has nothing to do with Web3 or blockchain.
Not Orbis Corporation / OrbisAPIOrbis Corporation makes plastic pallets; OrbisAPI is an AI/API marketplace. Neither is related to this tool.

If a search for orbisRPC or orbisrpc ps4 is about showing a PS4 game on Discord, the correct answer is this project: github.com/SirHumza/orbisRPC.

orbisRPC — FAQ

What is orbisRPC?

What does "orbisrpc ps4" mean?

It is a search for the orbisRPC project on the PlayStation 4: the PS4 homebrew tool that shows your current game on Discord without a PC. "Orbis" is Sony's internal codename for the PS4, which is where the name comes from.

Is orbisRPC the same as Orbis OS or OrbisPro?

No. Orbis OS is the PS4's FreeBSD-based operating system. OrbisPro is an unrelated Windows shell that mimics the PS4 UI. orbisRPC is neither — it is a Discord Rich Presence payload for a jailbroken PS4.

Is orbisRPC related to Orbis Protocol or Orbis Corporation?

No. Orbis Protocol is a Web3 social protocol and Orbis Corporation makes plastic pallets. orbisRPC is a PlayStation 4 homebrew tool. They only share the word "Orbis".

Is orbisRPC related to OpenOrbis or ORBISPatches?

No. OpenOrbis is a homebrew toolchain for developers and ORBISPatches is a game-update archive. orbisRPC is a separate end-user tool for Discord presence.

How is orbisRPC spelled?

The project name is orbisRPC — one word, capital RPC. People also search "orbisrpc ps4", "orbis rpc" or "Orbis RPC"; all of these mean the same PlayStation 4 Discord Rich Presence tool.
