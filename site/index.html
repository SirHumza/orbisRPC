A quick look at orbisRPC

Watch the demo, then grab the release if it fits your setup.

What it does

Your console, reflected in your profile.

One small background payload handles game detection and keeps your activity in sync.

01 / ACTIVITY

Show the game

See the foreground title and elapsed play time on your Discord profile.

02 / ARTWORK

Recognizable cover art

Title metadata adds artwork for supported retail, homebrew and retro games.

03 / RECOVERY

Connection fixes in 1.1

Version 1.1 fixes Discord gateway connection issues that made earlier builds unusable, including reconnect and heartbeat handling.

RELEASE NOTES · 1.1

Discord connection fixes

1.1 improves gateway reconnects and heartbeats, tightens WebSocket and credential validation, and makes config reload and installer flows more reliable.

Account note. orbisRPC uses a Discord user session token to set Rich Presence. Discord prohibits automating normal user accounts this way. Read the security notes before deciding whether to use it, and never share your token or config file.
