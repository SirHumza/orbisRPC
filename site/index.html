What is orbisRPC?

orbisRPC is a free, open-source Discord Rich Presence daemon for the jailbroken PlayStation 4. It shows the game you're playing — its name, cover art and play timer — on your Discord profile, posted straight from the console with no PC or companion script.

Not to be confused with Orbis Protocol (a Web3 social protocol) or the Orbis Cardano Layer-2. Different projects entirely — they only share the word "Orbis". orbisRPC has nothing to do with blockchain, crypto, or RPC nodes.

Install

Installed in about five minutes

Grab the setup PKG, run it once, and the daemon starts on every boot.

Install the PKG

Put orbisRPC Setup on the PS4 and open it from the home screen.

Pick INSTALL

It copies the payload to /data/payloads/ and writes your config.

Add your token

Paste your Discord token when asked. The guide walks you through it.

Auto-run

Let it add orbisRPC to the GoldHEN auto-run queue so it starts on boot.

Play

Restart, launch a game, and watch your Discord profile update.

FAQ

Questions

Does orbisRPC need a PC?

No. It runs entirely on the PS4 as a GoldHEN payload and talks to the Discord gateway over TLS 1.2 by itself. No computer, Python script or FTP bridge is needed at runtime — which is exactly what separates it from older PS4 rich-presence tools that require a PC to be on while you play.

What firmware does it support?

Jailbroken firmware 5.05 through 13.52, with 9.00 to 13.52 confirmed working on real hardware.

Does it show homebrew, PS1 and PS2 games?

Yes. Retail games come from Sony's TMDB, homebrew from pkg-zone, and more than 28,000 PS1/PS2/PSP classics from a curated community list — all with cover art.

Will it get my Discord account banned?

orbisRPC uses a Discord user session token, and token-based presence is against Discord's Terms of Service. This is standard for headless presence tools — every alternative in this category makes the same trade-off. The risk is yours to weigh.

Is it free and open source?

Yes — free, and the full source is on GitHub.

What if cover art doesn't show?

That's almost always a DNS blocker on the console. Add tmdb.np.dl.playstation.net to your nanoDNS exceptions and set the PS4 DNS to 127.0.0.1. The troubleshooting guide covers it step by step.

How do I show my PS4 game on Discord?

Install orbisRPC on your jailbroken PS4 — install the orbisRPC Setup PKG, open it, choose INSTALL, enter your Discord token, restart. After that, whatever game you launch appears on your Discord profile automatically, with cover art and a play timer.

Is there a PS4 Discord Rich Presence that doesn't need a PC?

Yes — orbisRPC. It runs entirely on the console. Other tools like PS4-Rich-Presence-for-Discord and playstation-discord-status are PC scripts that need a computer running while you play. orbisRPC needs no PC.

Does it work on a normal, non-jailbroken PS4?

No. orbisRPC requires a jailbroken PS4 running GoldHEN, because it installs as a payload. A stock console can't run it.

Do I need PSN or an internet connection?

No PlayStation account or PSN login is used. It just needs internet so the console can reach Discord and look up game metadata.

Does it work on PS5?

No — orbisRPC is built for the PlayStation 4 (GoldHEN), firmware 5.05 through 13.52.

Is this the same as the official PlayStation Discord integration?

No. Discord's official PlayStation link shows a basic PSN status. orbisRPC is separate homebrew that shows the exact game, cover art and a live timer, on a jailbroken console, without PSN.

Does it hurt game performance?

No meaningful effect. orbisRPC is a tiny background payload that polls about every 12 seconds and never hooks or modifies your games.

Can I hide which games show up?

Yes. Separate toggles (show_idle, show_media, show_homebrew, show_firmware) let you control exactly what gets posted.
