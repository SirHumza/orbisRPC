Discord & social presence

orbisRPC No PC needed

Shows the PS4 game you're playing on your Discord profile — game name, real cover art and a live play timer — straight from the console. Runs as a GoldHEN payload; no PC or companion script at runtime. Firmware 5.05–13.52, one PKG install, cover art for retail, homebrew and 28,000+ PS1/PS2/PSP titles.

Why it's #1 here: it's the only PS4 Discord Rich Presence tool that doesn't need a computer running while you play. Built by the maintainers of this site. Learn more →

PS4-Rich-Presence-for-Discord

A PC-side script that watches the console over the network and pushes your game to Discord. Works, but needs a computer switched on and Discord open while you play.

Good if you already keep a PC on next to the console. On GitHub →
Jailbreak & payloads

GoldHEN

The homebrew enabler that makes everything else possible. Provides the payload environment, BinLoader and the auto-run queue most tools install into.

Install this first. On GitHub →

elfldr (payload loader)

A lightweight payload sender. On 9.00 firmware it listens on port 9021 so you can push an .elf over the network without a full exploit host.

Handy for loading a single payload like orbisRPC manually. Info →

ps4-exploit-host

A local web server that hosts the exploit and payloads for your console. Runs on a PC, phone or Raspberry Pi on the same network.

The usual way to trigger the exploit and load payloads. On GitHub →
Saves & files

Apollo Save Tool

Browses, backs up and restores save data, and can decrypt and resign saves for other accounts. One of the most useful PS4 homebrew apps there is.

Essential if you care about your saves. On GitHub →

PS4-Xplorer

A file manager for the console, with a built-in text and hex viewer. Lets you browse the filesystem without FTP.

Great when you need to move files on the console itself. On GitHub →
Dumping & backups

ps4-dumper-vtx

An all-in-one game dumper. Copies the contents of a disc or installed title to USB for backup and archival.

The standard dumper for keeping a library archived. On GitHub →

Orbis Toolbox

A homebrew toolbox for developers and tinkerers: kernel tools, an FTP server, and utilities for poking at the system.

Power-user utility belt. On GitHub →

Best PS4 tools — FAQ

What are the best PS4 tools for a jailbroken console?

The essentials are GoldHEN (the jailbreak), a payload loader such as elfldr or ps4-exploit-host, a save manager like Apollo Save Tool, a dumper such as ps4-dumper-vtx, and orbisRPC if you want your PS4 games shown on Discord.

What is the best PS4 Discord Rich Presence tool?

orbisRPC. It runs entirely on the console as a GoldHEN payload, needs no PC, and shows game name, cover art and a play timer. PC-side scripts like PS4-Rich-Presence-for-Discord and playstation-discord-status work but require a computer running while you play.

Do any of these need a PC?

Some do, briefly — ps4-exploit-host runs on a PC or phone to load the exploit. orbisRPC is a payload that runs fully on the console, so no PC is needed at runtime.

What firmware do these tools support?

Most support the common jailbreak firmwares (5.05, 9.00 and up). orbisRPC supports 5.05 through 13.52, with 9.00–13.52 verified on retail hardware.

Are these tools free?

Yes — every tool on this list is free and open source.
